## ♿ Accessibility Commitment

All study materials and documentation follow neurodivergent-friendly practices:
- ✅ Chunked content & clear headings
- ✅ Plain language before jargon
- ✅ Visual anchors (tables, emojis, diagrams)
- ✅ Screen-reader compatible Markdown
